# tiny-llama

A minimal LLM inference engine built from scratch in C++/CUDA. Most code are generated by Claude Code.

## Roadmap

### Phase 1 — Core Ops (current)
- [x] Tensor class (CPU/CUDA, Float32/Float16/Int8/Int32)
- [x] RMS Norm / Layer Norm
- [x] Softmax
- [x] MatMul / BMM / Linear (cuBLAS)
- [x] RoPE (Rotary Position Embedding)
- [x] Scaled dot-product attention
- [x] Multi-Head Attention (MHA) with KV-cache
- [x] SiLU / GELU / element-wise mul
- [x] Token embedding lookup
- [ ] Transformer block (Attention + FFN + residual)

### Phase 2 — Model Layer
- [ ] KV-cache

### Phase 3 — Weight Loading & Tokenizer
- [ ] Load weights from `.safetensors` / `gguf` format
- [ ] BPE tokenizer (compatible with LLaMA tokenizer)
- [ ] End-to-end text generation (greedy / top-p sampling)

### Phase 4 — Server

### Phase 5 — Performance
- [ ] Flash Attention kernel
- [ ] CUDA Graph for static decode loop

### Phase 6 — Usability
- [ ] Benchmark suite vs llama.cpp
- [ ] Unit tests

## Build

```sh
export PATH=/home/disk1/caorenjie/cuda-12.2/bin${PATH:+:${PATH}}
export CC=/opt/compiler/gcc-12/bin/gcc
export CXX=/opt/compiler/gcc-12/bin/g++
export LD_LIBRARY_PATH=/usr/lib64:/home/disk1/caorenjie/cuda-12.2/lib64

mkdir build && cd build

cmake -DCMAKE_CUDA_COMPILER=/home/disk1/caorenjie/cuda-12.2/bin/nvcc \
      -DCMAKE_CXX_COMPILER=/opt/compiler/gcc-12/bin/g++ \
      -DCMAKE_CUDA_HOST_COMPILER=/opt/compiler/gcc-12/bin/g++ \
      -DCMAKE_CUDA_ARCHITECTURES=native \
      ..

```
